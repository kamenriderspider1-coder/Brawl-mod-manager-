But Brawl normally loads mod files from the Wii's SD card or USB, not directly from cloud storage. The long-term goal is for a Wii companion to fetch selected files over Wi-Fi when technically supported.

How mods get onto the Wii

Browse here from your phone or computer. When you choose a mod, its creator's page provides the download. To play it, the file still needs to reach the Wii's SD card or USB drive using the mod's required folder structure and loader. Automatic Wii-side downloading is a separate feature we can build and test next.

Only creator-authorized files should be mirrored. This catalog links to original sources and does not claim that every listed mod is tested or compatible. Always check region, game version, loader, and installation notes.
