☁️ Brawl Mod Cloud Library

Discover Super Smash Bros. Brawl mods, collect their source details, and prepare a cloud library for your Wii setup.

Important: This first version discovers and organizes mods. It does not silently copy every file from the internet. Downloads must respect each creator's permissions and the source site's rules. The cloud upload button stays disabled until a storage provider is connected.

Cloud connection needed

GitHub hosts this app's code and catalog, but it is not the right place for a large personal mod archive. To finish automatic file transfers, the project needs a separate storage provider with a secure account connection.

The app must not ask you to paste private passwords or secret access tokens into a public GitHub file. We will use the provider's proper sign-in or secure server-side credentials.

How automatic importing will work

  1. Search supported mod sources and show creator, file details, and compatibility notes.
  2. You select the files you want and confirm they may be stored.
  3. The importer downloads only supported files from their original source.
  4. The cloud connector uploads them to your private storage and records their source and checksum.
  5. The Wii manager reads compatible files through the selected network-loading method. This is a separate compatibility step.
Source references: GameBanana API · BrawlVault. Some sources may not expose a stable API or may restrict automated downloads. No files are mirrored by this prototype.
