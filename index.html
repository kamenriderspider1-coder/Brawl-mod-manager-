☁️ Brawl Cloud Library

Free public file hosting

The mod files are stored as downloadable assets in GitHub Releases. This uses the existing project repository, not Google Drive, a paid storage account, or a separate storage provider.

Browse / Download Mods ↗ Add a Release / Upload Files ↗

Release files in this repository are public. Do not upload private files, personal information, or files you do not have permission to distribute.

How to add mods to your cloud library

1. Open Releases

Use “Add a Release / Upload Files” and sign in to GitHub.

2. Create a release

Give it a clear title, such as “Brawl Mod Pack 1”.

3. Attach your files

Drag permitted mod archives into the release attachment area, then publish it.

4. Download on your Wii setup

Open the release on a computer, download the chosen archive, and copy its supported files to the SD card.

🎮 Wii Brawl Mod Manager

Current release: v20

Install the Homebrew Channel app package from the latest available release.

Download Wii Manager ZIP ↗ Release details ↗

Extract the ZIP and copy its app folder into sd:/apps/ on your Wii SD card.

Move a downloaded mod to the Wii

  1. Download the mod archive from the Brawl Cloud Releases library on a computer.
  2. Extract it if the mod's instructions require that.
  3. Copy the files into the folder specified by that mod's instructions, or into sd:/brawl-mods/ for the manager's file list.
  4. Put the SD card back in the Wii and open Brawl Mod Manager from the Homebrew Channel.
Wii internet syncing is not in the current v20 app yet. This version browses files already on the SD card. A later version needs an HTTPS downloader and a compatible mod catalog before it can download directly over Wi-Fi.
Brawl Cloud uses GitHub Releases as a public file library. GitHub's public release downloads do not require a personal access token. No Google sign-in, Google Drive API, or paid cloud-storage service is used.
