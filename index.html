Brawl Mod Manager

The Wii app lives on SD. The mod library lives in the cloud.

The SD card holds the Brawl Mod Manager homebrew app. The GitHub cloud library is intended to host the mod files, which the Wii manager will access over Wi-Fi through a compatible network-loading system.

How the Wii app and cloud library fit together

1. Install the manager on SD

The SD card stores the Wii homebrew app and its network-client files.

2. Keep mod archives in the cloud

Store redistribution-permitted mod archives as GitHub Release assets. Keep a catalog of names, versions, and archive URLs.

3. Connect over Wi-Fi

The Wii app reads the cloud catalog and displays available mods. This connection is a planned feature, not present in v20.

4. Load compatible files remotely

A Wii-compatible network filesystem or streaming bridge must serve the files in a format the Brawl loader can use. Not every mod or loader supports remote access.

Populate the cloud mod library

  1. Open New GitHub Release.
  2. Give the release a clear mod name, version, base-game requirement, and compatibility notes.
  3. Attach only archive files you have permission to redistribute, then publish the release.
  4. Add the archive's direct asset URL and metadata to cloud-mods.json.
  5. The future Wii network client will read this catalog and load supported files through the network bridge.

Release assets are public. Do not upload private information or files you do not have permission to distribute.

Brawl Cloud is designed around GitHub Releases as the public archive host and GitHub Pages as the catalog interface. The Wii SD card holds the manager app; the cloud holds permitted mod archives. Network streaming into Brawl is not implemented in the current v20 app and will require a Wii-compatible bridge and loader integration.
