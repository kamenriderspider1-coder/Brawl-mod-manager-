How to add mods to the cloud

1. Add the archive

Put a mod file you are allowed to redistribute in cloud-library/files/ in the GitHub repository.

2. Add its catalog entry

Add the file path, name, type, creator, and source details to cloud-library/catalog.json.

3. Publish

After the commit and Pages deployment, the mod appears here as a downloadable item.

This is a public, repository-backed library, not private or unlimited storage. Large archives and files you do not have permission to redistribute should stay at their creators' official download pages. A secure in-browser upload feature would require a protected sign-in service, so this public page deliberately does not ask for passwords or access tokens.
