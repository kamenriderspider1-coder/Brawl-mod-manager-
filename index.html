How the transfer works right now
  1. Use the importer below to download and check a creator ZIP.
  2. Download the prepared ZIP bundle to this Mac.
  3. Open the bundle with the built-in Archive Utility to extract it.
  4. In the official MEGA tab, upload the extracted mod folder to Brawl Mods.

Automatic account-to-account upload is not available: MEGA does not publish an official drop-in browser JavaScript SDK for third-party pages. The commonly used MEGAJS package is unofficial, so this app intentionally does not ask for your MEGA credentials.

Mod download pipeline

  1. Find a mod online or paste its source/download link.
  2. Fetch the permitted archive through a processing service.
  3. Extract and validate the archive.
  4. Upload the extracted mod folder into your MEGA account.
  5. Publish its metadata to the Wii library.

The assisted import tool below downloads a creator ZIP through the cloud service, validates its paths, extracts it in your browser, and packages the extracted folder for download. You then upload the extracted folder to MEGA using its official website.

Wii compatibility is not guaranteed by a filename. Before importing, confirm the creator page says the mod supports the original Wii version of Super Smash Bros. Brawl, and check its base-game/loader requirements. Dolphin-only, Ultimate, and other-game mods should not be imported. The scanner only follows supported HTTPS creator domains.

Choose a catalog entry and a ZIP. The app validates and prepares a folder-preserving ZIP bundle. Limits: 100 MB compressed, 300 MB extracted, and 1,000 files per import.

Only import files you are allowed to download and store. ZIP files are inspected in-browser. Password-protected ZIPs, split archives, RAR/7z files, and very large packs are not supported by this first version.

How the Wii app and cloud library fit together

1. Install the manager on SD

The SD card stores the Wii homebrew app and its network-client files.

2. Keep mod archives in the cloud

Store the extracted mod files in your connected MEGA account. Keep a catalog of names, versions, and archive URLs.

3. Connect over Wi-Fi

The Wii app connects to the Cloud Storage service and displays available Drive-backed mods. This connection is a planned feature, not present in v20.

4. Load compatible files remotely

A Wii-compatible network filesystem or streaming bridge must serve the files in a format the Brawl loader can use. Not every mod or loader supports remote access.

Populate the cloud mod library

  1. Open New GitHub Release.
  2. Give the release a clear mod name, version, base-game requirement, and compatibility notes.
  3. Attach only archive files you have permission to redistribute, then publish the release.
  4. Add the archive's direct asset URL and metadata to cloud-mods.json.
  5. The future Wii network client will read the Cloud Storage app's library and access supported files through the network bridge.

Release assets are public. Do not upload private information or files you do not have permission to distribute.

Brawl Cloud is designed as a separate Cloud Storage app that connects to MEGA. The Wii SD card holds the manager app; your cloud account holds permitted extracted mod files. Network streaming into Brawl is not implemented in the current v20 app and will require a Wii-compatible bridge and loader integration.
