How the two libraries fit together

1. Keep REX on SD

Leave your current REX installation where it is. The manager should detect it without replacing its files.

2. Store other packs in GitHub

Upload only mod packs you have permission to share as assets on GitHub Releases. REX does not need to be uploaded.

3. Browse the cloud library

Use the Releases link to see available cloud-hosted packs and their descriptions.

4. Check compatibility

Only compatible additions can safely be combined. Remote access requires a supported network-loading method; a GitHub link alone is not a Wii filesystem.

Add packs to the cloud library

  1. Open New GitHub Release.
  2. Give the release a clear pack name and description.
  3. Attach the permitted mod archive(s), then publish the release.
  4. Use the Releases page to browse the public cloud library.

Release assets are public. Do not upload private information or files you do not have permission to distribute.

Brawl Cloud uses GitHub Releases in this repository as its public file library. No separate paid storage service, Google Drive connection, or API key is used. GitHub Pages serves this information page; publishing changes may take several minutes to appear.
